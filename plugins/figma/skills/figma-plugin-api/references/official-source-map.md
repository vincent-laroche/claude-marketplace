# Official Plugin API reference coverage

Audited 2026-08-02 from the official Figma developer sitemap and full page content.

The current plugin corpus contained 477 non-history pages:

- 39 plugin development guides.
- 189 API overview, global, node, and type pages.
- 245 individual property/method pages under `/api/properties/`.
- 4 aggregate index pages for global objects, nodes, shared properties, and data types.

All 151 historical pages in the Plugin API update archive were also fetched and read for evolution/deprecation context.
