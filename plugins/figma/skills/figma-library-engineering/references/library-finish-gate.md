# Library Finish Gate

Before handoff, verify authority and source, reachable variables/styles, auto-layout and bindings, minimal public variant axes, intended nested instances, no broken/remote instances or unexplained raw values, editable Layers structure, and representative desktop/mobile frames. Report library publish and sharing state separately.

If a mutation fails mid-way, inspect the affected tree and variables, make one recovery change, then re-run the gate. Do not bulk-clean a library without approval.
