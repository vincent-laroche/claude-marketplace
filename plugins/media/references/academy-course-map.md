## Plugin routing

- Use `higgsfield-image` for stills, edits, reference composition, and finishing.
- Use `higgsfield-video` for isolated generated motion and video post tasks.
- Use `higgsfield-cinema-studio` for project/Elements/director workflows.
- Use `higgsfield-canvas` for reusable node graphs and visual assembly.
- Use `higgsfield-supercomputer` for planned agent work, connected tools, and schedules.
- Use `higgsfield-mcp-cli` for the official agent/terminal interfaces.
