## Current facts that require revalidation

- Model roster, reference limits, resolution, duration, audio, and exact control labels are selected-model UI state.
- Cinema Studio Elements require current model support for the `@` control.
- Supercomputer connectors, permissions, schedules, and skills are account state, not plugin facts.
- MCP and CLI installation instructions can change. Re-open the official page/repository before installing or updating.
