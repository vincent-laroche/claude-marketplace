# Higgsfield model selection

Choose by the hardest requirement in the brief. Do not use this as a substitute for checking the selected model's live inputs and controls.

## Decision boundaries

### Soul ID versus Soul Cast

- Use Soul ID when the character must be a specific real person and the user has suitable, consented training photos.
- Use Soul Cast when the actor should be invented and controlled by genre, era, archetype, identity, physical appearance, details, and outfit.
- Do not use Soul Cast as a shortcut for reproducing a real person's likeness.

### Seedance 2 versus Kling 3

- Use Seedance 2 for a cohesive cinematic shot where motion stability, camera logic, atmosphere, and downstream editing matter more than explicit internal scene segmentation.
- Use Kling 3 when the video needs named scene beats, assigned durations, start or end frame constraints, recurring elements, or integrated sound.
- Run a controlled comparison when both fit a high-value shot. Keep references, prompt intent, duration, crop, and review criteria fixed.

### Kling 3 versus Kling Motion Control

- Use Kling 3 when motion can be directed from a prompt and scene structure.
- Use Kling Motion Control when the exact performance already exists as a reference video.
- Do not describe complex choreography in prose if a clean performance reference is available and fidelity to that motion is the primary requirement.

### Nano Banana 2 versus Soul 2.0

- Use Nano Banana 2 for structured layouts, text-bearing visuals, localization, infographics, product compositions, and fast campaign variations.
- Use Soul 2.0 with Soul ID when recurring human identity is the protected attribute.
- A marketing composition can use both: establish the person with Soul ID, then use a layout-oriented model or native design tool for copy and final composition.

### Structured image models

- Use Nano Banana Pro for reasoning-led layout and exact prompt constraints.
- Use GPT Image 2 when photoreal commercial finish and visible text are the leading requirements.
- Use Seedream Pro for dense infographics, multilingual text, and surgical edits; use Seedream Lite for context-aware natural-language iteration.
- Use FLUX.2 when several references, exact counts, spatial constraints, or explicit color values must coexist.
- Use Soul 2.0 when fashion, visual culture, photographic medium, palette, and editorial point of view are the main creative problem.

### Multimodal video routes

- Use Kling O1 when the same workflow must generate from references and transform source footage.
- Use Gemini Omni Flash for the fastest mixed-input development and revision loop.
- Use Wan 2.7 for a direct still-to-motion route driven by frame guidance or a preset.

## Comparison protocol

1. Write one source brief with protected attributes and a delivery use.
2. Prepare identical source assets for each eligible model.
3. Change only the model-specific controls needed to express the same intent.
4. Compare identity or product fidelity, instruction adherence, composition, motion, camera, audio, edit points, and delivery crop.
5. Select a winner for that shot class, not a universal winner.
6. Record the winning model-and-input pair as a reusable production pattern.

## Other models

The platform also exposes additional image, video, and audio models. Do not invent a durable specialization from a catalog label alone. Inspect official product guidance and live controls, then add a focused skill only when there is enough evidence to state its selection advantage, input strategy, and failure modes.
