# Higgsfield Soul 2.0

Read `../../references/production-contract.md`. Use Soul 2.0 when visual taste, fashion language, cultural specificity, natural body language, and a cohesive photographic point of view matter more than dense layout logic.

## Direct with the model's native system

- Put the most important aesthetic direction first and keep the prompt focused.
- Name the era, photographic medium, emotional register, styling attitude, and setting.
- Use one curated preset as a style anchor across a series instead of rewriting the entire look every time.
- Use Soul HEX to extract a palette from a reference and Color Transfer to carry an approved grade across existing outputs.
- Build a custom Moodboard from at least five visually cohesive, face-free images when the required world is more specific than a preset.
- Add Soul ID only when a recurring real person's likeness must be protected.

## Build a coherent series

1. Approve one palette, preset or Moodboard, camera feel, and skin treatment.
2. Generate a neutral hero frame before variations.
3. Change wardrobe, pose, crop, or location one variable at a time.
4. Transfer the approved color treatment across the accepted set.
5. Review the images together, not only individually.

## Best uses and limits

Use Soul 2.0 for fashion editorials, personal-brand portraits, culture-aware social imagery, lookbooks, and image series that must feel authored. Do not use it as the first choice for dense infographics, complex multilingual layouts, or exact technical diagrams.

Reject plastic skin, stiff posing, costume-like era interpretation, inconsistent palette, identity drift, or a frame that is fashionable but wrong for the brand.
