# Higgsfield Kling 3

Read `../../references/production-contract.md`. Use Kling 3 when the clip needs explicit structure rather than a single emergent motion.

## Exploit its native structure

Kling 3 supports:

- two to six described scenes inside one short generation;
- assigned duration for each scene;
- start and end frame guidance, including end-only resolution;
- stable scene Elements such as characters, products, and objects;
- physics-aware subject and camera motion;
- video with or without generated audio.

Confirm the exact controls in the live model panel before execution.

## Build the scene plan

1. Write one overall concept, style, and camera logic.
2. Define each scene as a single beat with subject, action, camera, and intended transition.
3. Assign duration according to information density. Give the hook and final resolution enough screen time to read.
4. Add frame constraints only when a visual entry or destination is genuinely required.
5. Add Elements only after their identity or geometry masters pass review.
6. Decide whether audio should be generated with the scene or designed later.

## Best uses

- short narrative sequences and product stories;
- macro material or detail studies;
- pans, tracks, and reveals that need stable physics;
- recurring characters, mascots, or products;
- clips whose rhythm must be planned before generation;
- sound-led prototypes where motion and audio timing should be assessed together.

## Review

Inspect every scene boundary, character and product continuity, element count, spatial relationships, impact physics, camera direction, micro-sounds, dialogue clarity, and the final frame. If one beat fails, simplify or regenerate that structure rather than hiding the defect with faster editing.

Use `../higgsfield-seedance-2` for a more continuous cinematic shot and `../higgsfield-kling-motion-control` for performance-driven motion transfer.
