# Higgsfield Nano Banana 2

Read `../../references/production-contract.md`. Prefer Nano Banana 2 when semantic clarity, speed, layout compliance, text, and structured composition matter together.

## Use its selection advantage

Nano Banana 2 is a practical default for:

- layered instructions and explicit object placement;
- infographics, diagrams, and structured data visuals;
- legible text and localized image variants;
- product mockups and marketing compositions;
- rapid high-resolution iteration;
- maintaining several subjects or recurring objects within one controlled workflow.

Use Nano Banana Pro instead when maximum factual accuracy, fidelity, or studio-grade precision outweighs iteration speed. Use Soul 2.0 with Soul ID when a specific real person's likeness is the protected attribute.

## Structure the brief

Write:

1. delivery format and layout grid;
2. subject and product truth;
3. exact object count and positions;
4. hierarchy and negative space;
5. lighting, material, and visual style;
6. exact copy and language, if text must appear;
7. protected references and exclusions.

For a complex composition, number the required elements and describe their relationships. Do not rely on vague phrases such as "premium layout" or "professional infographic."

## Production strategy

- Use one approved composition as the master before generating campaign variations.
- Separate factual source material from visual direction. Verify claims, names, labels, and data before prompting.
- Keep critical legal, medical, transactional, or conversion copy as native editable text whenever exactness and future revision matter.
- For localization, lock the layout and visual hierarchy, then change language and culturally specific imagery intentionally.

## Review

Check spelling, number of objects, position, hierarchy, product geometry, reference resemblance, factual correctness, and delivery crop. Treat plausible-looking diagrams or packaging as unverified until compared with the source.
