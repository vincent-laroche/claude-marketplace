# Higgsfield asset continuity

Read `../../references/production-contract.md` before creating or training an asset. Continuity starts with a reviewed source; it cannot be repaired by repeating a broad prompt.

## Build the asset hierarchy

1. Preserve the original source and label its role: identity, product geometry, location, prop, or style.
2. Make one master that passes close visual review at the intended crop.
3. Create the reusable platform asset only from that master: a Cinema Studio Element or a Soul identity where the current interface supports it.
4. Store the accepted name, project, source, purpose, limitations, and last approved output alongside the production record.

## Character and product rules

Character sheets must show a stable face, silhouette, clothing/hair rules, and coherent lighting without duplicate bodies, conflicting views, extra limbs, fake text, or decorative elements that the video model will misread. Product masters must preserve actual construction, logos, dimensions, and material behavior; a visually plausible replacement is not a faithful product asset.

## Test continuity before scaling

Put the asset into one narrow test shot with a stable location. If it drifts, identify whether the failure comes from the master, asset/Element, model, reference count, camera/motion instruction, or competing style direction. Change one variable, rerun, and preserve successful master/shot pairs.

Use Cinema Studio Elements for project-scoped scene assets. Use Canvas to expose the master-to-variation graph. Use `../higgsfield-soul-id` for a consenting real person's reusable identity and `../higgsfield-soul-cast` for a fictional actor designed from casting controls.
