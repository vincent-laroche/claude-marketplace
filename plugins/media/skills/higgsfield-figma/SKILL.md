# Higgsfield for Figma

Read `../../references/production-contract.md`. Treat the surrounding Figma file and its approved visual system as the source of truth.

## Choose the correct tool

| Tool | Use it for |
| --- | --- |
| Generate AI Image | Create a new visual from the file's subject, palette, lighting, and mood. |
| Generate AI Video | Add a loop, background motion, or hero animation from a prepared composition. |
| Remove Background | Isolate a subject for components, masks, and layered layouts. |
| Relight | Align direction, contrast, warmth, and atmosphere with adjacent imagery. |
| Color Grading | Apply one visual mood across mixed stock, client, and generated assets. |
| Expand | Recompose a tight source for new aspect ratios without rebuilding it. |
| Angles | Produce a coherent product angle set from one clean product photo. |

## Build a visual-system workflow

1. Select the destination frame before running a tool.
2. Identify one approved visual master for palette, lighting, contrast, and texture.
3. Generate or refine one asset until it matches that master.
4. Use Relight and Color Grading to harmonize outside sources rather than regenerating accurate client or product photography unnecessarily.
5. Use Expand to create responsive crops while protecting the original subject and composition.
6. For catalogs, validate the front, side, and three-quarter Angles against real product geometry before using the set.

Results arrive as normal image or video layers. Apply native Figma constraints, masks, components, and auto layout after placement. Keep typography, legal copy, and interface text native and editable.

Use a sharp, clean, well-lit source for refinement tools. Reject any output that changes the protected product, face, logo, or material merely to match the visual mood.
