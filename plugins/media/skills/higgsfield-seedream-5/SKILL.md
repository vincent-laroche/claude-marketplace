# Higgsfield Seedream 5

Read `../../references/production-contract.md`.

## Choose the variant

- **Seedream 5 Lite:** use for fast, context-aware iteration, natural-language intent, live-world context, broad multi-reference work, and coherent variations.
- **Seedream 5 Pro:** use for high-density infographics, point-specific edits, group compositions, multilingual typography, factual structure, and maximum precision.
- **Seedream 4.5:** retain as a controlled fallback when straightforward instruction adherence is enough or continuity with an approved older production matters.

Confirm the current reference allowance and output controls in the live panel.

## Generation workflow

1. State the intended use, subject, composition, mood, spatial relationships, and protected references.
2. Assign each reference a role rather than uploading an unlabelled set.
3. For Pro, specify hierarchy, data relationships, exact copy, and the element that may change.
4. For Lite, describe the creative intent clearly and let the model infer supporting atmosphere without overconstraining every detail.
5. Approve one master before expanding variants.

## Editing workflow

Describe one local change in plain language: replace the product, recolor the garment, correct a label, move focus, change lighting, or replace the background. Protect all non-target regions explicitly and compare them with the original after the edit.

Use a native text or design tool when critical copy must remain fully editable. Verify current-event, data, or public-figure imagery against the source even when the model uses live context.
