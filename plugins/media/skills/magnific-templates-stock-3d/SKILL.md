# Magnific Templates, Stock, Explore, and 3D Scenes

## Templates

Templates accelerate a known production pattern: social-format packs, catalog cards, brand books, or a starter Space. They are drafts, not brand authority.

1. Inspect the template structure, model/tool dependencies, aspect ratios, input requirements, and output destination.
2. Copy or derive a working version rather than overwriting the template source.
3. Replace sample copy, assets, colours, and claims with approved inputs.
4. For a Space template, use `magnific-spaces-and-flows`; for layout templates, use `magnific-designer`.
5. Simulate any run and obtain approval before paid generation.

## Stock and Explore

- **Explore** is for ideas and surface discovery. It has no approval, ownership, or commercial-rights implication.
- **Stock** is a source-acquisition surface. Search and inspect first; verify the current license, resolution, price, and intended use before download.
- A stock download can spend credits and creates account state. Run cost preflight and request exact approval. File the accepted result with source/licensing information; do not silently substitute it for an owned brand asset.

## 3D Scenes

Use 3D when a spatial object, camera, lighting, or reusable scene geometry is the point of the work. Do not use it merely to decorate a flat asset that Designer or image editing can handle.

1. Define object/scene purpose, camera view, material, environment, animation need, output format, and reference rights.
2. Inspect current `models3d` capability/schema and the relevant official documentation; 3D model support changes frequently.
3. Treat generated 3D output as a new creative asset: simulate cost, obtain approval, render/proof it, then review silhouettes, materials, scale, topology/readiness, and final camera output.
4. Store approved reusable scene objects in the Project/Library system with source and usage notes.

Use `magnific-production-safety` before any generation/download and `magnific-library-and-projects` for durable organisation.
