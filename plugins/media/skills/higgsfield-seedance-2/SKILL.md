# Higgsfield Seedance 2

Read `../../references/production-contract.md`. Use Seedance 2 when the primary need is a coherent cinematic shot that remains usable across its full duration.

## Design one continuous shot

Write the brief as:

**story purpose → subject → one main action → environment → camera path → spatial relationships → light continuity → pacing → audio intent**

Favor clear motion arcs and a camera move that can be understood in physical space. Avoid stacking multiple unrelated events into a short shot.

## Strong shot classes

- controlled pans, tracking shots, and reveals;
- slow atmospheric shots where temporal defects would be exposed;
- macro product or texture studies;
- motion that depends on weight, depth, and stable spatial relationships;
- foundational footage intended for editing, compositing, typography, or continuation.

The official technical overview frames these as the model's production direction rather than a guarantee for every prompt. Validate the actual shot instead of assuming that the model label solves continuity.

## Production loop

1. Start from a clean still when a known composition or identity must be anchored.
2. Make the shortest useful proof with one subject and one camera idea.
3. Inspect lighting, texture, identity, spatial continuity, motion physics, and camera direction across the entire clip.
4. Check whether the opening and closing frames create clean edit points.
5. Change one variable after a failure: source frame, action, camera, pacing, or duration.

Use `../higgsfield-kling-3` when explicit internal scene beats, frame constraints, or recurring Elements are more important. Use `../higgsfield-kling-motion-control` when a performance video must define the exact motion.
