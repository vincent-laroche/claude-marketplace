# Magnific Designer

Designer is the finishing and layout surface. Use it when the objective is an editable composition, a resized set of deliverables, or a branded design system—not when a new photographic subject is needed.

## Choose the path

| Job | Best starting point |
|---|---|
| Preserve a flat source but make parts editable | Auto Layers |
| Produce several aspect-ratio versions from one approved source | Auto Resize |
| Build an editable social, product, email, or brand-book page | Designer page/layout workflow |
| Need new imagery first | `magnific-image-production`, then bring an accepted image into Designer |
| Need a creative multi-scene animation | `magnific-spaces-and-flows` / `magnific-video-production` |

## Editable-design workflow

1. Start with an approved source asset and explicit intended formats. Do not auto-layer or resize a draft that has unresolved product, identity, or brand issues.
2. Inspect current Designer capabilities and the exact input constraints. Use `design_auto_layers` only if extracting editable regions is actually useful; choose a small deliberate layer count rather than maximising it.
3. Use `design_auto_resize` only after listing the concrete aspect ratios and reviewing whether text/image hierarchy can survive them.
4. Apply brand truth from `/Users/vMac/08_brand/brand-design-system` for customer-facing work. Do not rely on palette values remembered from an old Space, image, or template.
5. Review every generated layer/page for missing details, accidental text extraction, crop damage, legibility, and mobile-safe hierarchy.
6. Simulate/confirm any paid operation, obtain approval, then keep accepted design pages and their source creation linked in the chosen project.

## Templates are a starting surface

A “brand book,” catalog card, or social template is a layout accelerator. It does not establish Hair Solutions branding, make external copy true, or make a design customer-ready. Preserve the source template and create an intentional derived working version before broad edits.

Use `magnific-templates-stock-3d` to select a template, `magnific-library-and-projects` to store reusable building blocks, and `magnific-production-safety` before any sharing/export/publication step.
