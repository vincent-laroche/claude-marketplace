# Higgsfield Wan 2.7

Read `../../references/production-contract.md`. The durable Higgsfield workflow exposes a first frame, optional end frame, prompt, general generation, and preset-led motion routes. Recheck the live model panel before execution.

## Build the shot

1. Start from an approved image with enough negative space for the intended motion.
2. Add an end frame only when the final composition matters.
3. Describe subject action separately from camera movement.
4. Use a preset when it expresses the camera or VFX behavior more precisely than prose.
5. Make one short proof before increasing complexity.

## Choose Wan versus neighboring routes

- Use Wan when a still image and preset or frame guidance already define the shot.
- Use Seedance 2 for a coherent atmospheric camera shot and downstream editability.
- Use Kling 3 for explicit internal scenes, stable Elements, and planned pacing.
- Use Kling Motion Control when a real performance video must own the motion.

Reject morphing at the transition, changing product geometry, clipped motion, unstable lighting, or an end state that misses the supplied frame.
