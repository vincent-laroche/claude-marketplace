# Higgsfield Kling O1

Read `../../references/production-contract.md`. Kling O1 is a unified multimodal route with separate generation and edit workflows.

## Generate mode

Use:

- one image plus prompt;
- multiple role-labelled image references;
- start and end frames plus prompt.

Build stable characters, outfits, props, environments, fashion motion, product shots, establishing shots, or narrative moments. Confirm the live reference and duration controls before execution.

## Edit mode

1. Upload the source video.
2. Add only the identity, outfit, lighting, prop, or style references required for the change.
3. Add a motion reference when camera movement, pacing, rhythm, or angle transitions should transfer.
4. Describe one coherent transformation.
5. Compare protected subjects, geometry, camera continuity, and untouched regions with the source.

## Decision boundary

Use Kling O1 when generation and transformation need to share a multimodal reasoning system. Use Kling 3 for explicit multi-scene structure, Kling Motion Control for faithful performance transfer, and Gemini Omni Flash for the fastest mixed-input development loop.
