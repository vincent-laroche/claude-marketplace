# MailerLite forms and capture

1. Run email-marketing-preflight. Read ../../references/authority-map.md, action-gates.md, and
   email-quality-gates.md.
2. Define purpose, placement, fields, group assignment, consent language, confirmation behavior,
   success state, attribution, privacy link, and follow-up automation before building.
3. Collect the minimum data needed. Do not pre-check marketing consent or hide the subscription
   purpose.
4. Create or update a draft form only when requested. Resolve by exact name and verify the target
   group, duplicate handling, mobile layout, keyboard access, validation, and error states.
5. Test with synthetic data only unless Vincent approves a real subscriber operation.
6. Return form ID and dashboard link, status, field mapping, group, consent text, test result, embed
   requirements, and publication blocker.

Creating a form is not approval to publish it, embed it, or enable its follow-up automation.
